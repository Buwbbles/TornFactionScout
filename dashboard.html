Faction/Scout

ranking every faction the api will show us

Load a dataset

Run python3 scout.py run to produce factions.json, then drop it here.

Or serve the folder — python3 -m http.server 8000 — and open localhost:8000/dashboard.html to load it automatically.

What counts, and how much
Narrow the field

Scores are percentile ranks inside the filtered set, so they shift as you filter. Win rates under five wars are pulled toward 50% — a 2–0 record is not a 100% faction.

Your API key

This site never asks for one. Everything here is built from data the Torn API makes public about factions, collected once by whoever runs this site and served to everyone as a plain file. No account, no login, nothing sent anywhere.

Where the numbers come from

Faction details, rosters and ranked war results come from the official Torn API. Battle stats are private, so those columns are public estimates from FFScouter and are approximations. Faction perks are not exposed by the API for factions you're not in.
